# NosyGrid 0.29.0

This release includes the changes developed since 0.26.3.

- Add fractional row ordering with per-view **Maximum decimal places** (0–6, default 2). Moves preserve existing ranks where possible and rebalance only a local range when gaps are exhausted.
- Add **Order storage: Note property / Base view**. Base-view ordering performs no Markdown-file I/O for pure reorders and saves independent ranks per view. Existing views keep note-property mode, which now checks only changed notes and surrounding anchors.
- Persist group-value catalogues per Base view. Seen values and paths stay available as empty destinations after their last note changes, moves or disappears, without requiring another vault note as evidence.
- Add trash controls to remove values from the view, including their matching visible rows, without deleting or changing notes. Removed values remain suppressed after refresh/reopen; adding them again restores them.
- Enable **Add group** for horizontal as well as vertical note-property groups, including nested and empty filtered views. Add **Add empty group** for unset values.
- Preserve typed values, link interactions, colors, visibility and vertical group ordering. Rename grouping-level creation to **Add group by** to distinguish it from value creation.
- Preserve existing catalogues during setting-save failures and test explicit removal/re-addition, empty values, nested paths and reopen persistence.

Removing a group value changes view visibility, not note properties. Formula/computed property values can be remembered and removed; arbitrary new values can be created for note-property groups.

Base-view ranks are not available to native table views, formulas or query filters. File renames are tracked while the Base view is open; a note renamed while that view is closed appears as a new result on reopening. Group membership changes still update note properties. Existing documentation screenshots remain real Obsidian captures from 0.26.3, as documented in their provenance.
