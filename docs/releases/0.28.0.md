# 0.28.0

- Add **Order storage: Note property / Base view**. Existing views keep note-property storage.
- Base-view ordering saves a per-view rank map, preserves filtered-out ranks, appends new results, tracks renames in open views and prunes deleted paths on the next move. Switching modes preserves both stored orders.
- Pure view reorders perform no Markdown reads or writes, patch the existing rows immediately, and save the view configuration. Undo restores view ranks; save failures restore the display.
- Positioned group moves combine membership edits and view ordering in one undoable operation. Membership properties still live in notes.
- Note-property reordering now fresh-reads only changed notes and neighbouring anchors instead of every note in the group. Remove duplicate full-destination checks on positioned group moves.

Renames made while a Base view is closed are treated as new results when it reopens. View-only ranks cannot be used by native tables, filters or formulas. Existing screenshots remain the genuine 0.26.3 captures described in their provenance.
