# 0.27.0

- Add per-view **Maximum decimal places** (0–6, default 2) for the ordering property. Setting changes leave existing frontmatter untouched.
- Reordering uses fractional ranks to update only the moved notes when the destination gap permits it. Beginning/end moves extend the numeric range instead of renumbering the table.
- When precision is exhausted, rebalance the smallest surrounding range needed to fit the moved block.
- Apply the same allocation to positioned multi-row and cross-group drops, preserving destination anchors whenever possible. Group-header drops continue to preserve existing ranks.
- Use exact decimal integer units during allocation and check numeric representability. Preserve undo, rollback, conflict checks, empty values and descending ordering.

Existing documentation screenshots are genuine captures of the earlier 0.26.3 build, as recorded in their provenance. They do not show the new precision setting.
