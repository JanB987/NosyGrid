# NosyGrid 0.26.1

First GitHub release, prepared for Obsidian distribution.

- Editable Bases tables with numeric drag ordering and undo.
- Inline property/list editors, wiki-link completion and link dragging.
- Cell-range selection, clipboard operations and multi-row moves.
- Nested horizontal and vertical grouping, persistent widths/collapse/order and continuous empty columns.
- Floating drag previews, source shadows and cancellation/rollback behavior.
- Per-value group colors and native per-group/overall summaries.
- MIT license, illustrated README and automated build/test/release workflows.

Requires Obsidian 1.10.2+ with the Bases core plugin enabled. Install `main.js`, `manifest.json`, and `styles.css` together in `.obsidian/plugins/nosygrid/`, then restart Obsidian and enable NosyGrid.

This is an initial pre-1.0 release and is not yet listed in the Community plugins directory. Back up your vault before use. Desktop mouse/keyboard interactions are tested; mobile touch dragging is not yet validated.
