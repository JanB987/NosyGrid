# NosyGrid 0.30.0

Copy selected notes as links, paste multiple links into supported property editors, and drag notes to external destinations. This release also fixes duplicate retained groups and removes the selection counter that could shift the table.

## New

- Copy one or multiple selected rows with Ctrl/Cmd+C or the row-handle **Copy link / Copy links** menu. Links use full vault paths and follow the visible row order.
- Paste copied links into Markdown note bodies. Recognized native Text property editors receive the links on one line.
- Paste multiple copied links into recognized native List **add-item fields**, creating a separate entry for each note while preserving existing items.
- Drag file-name links or selected rows toward external destinations using Obsidian's native file-drag handling when available.
- Add dragged note links to compatible NosyGrid Text and List cells.

## Fixes

- Merge duplicate retained groups caused by changes in native group representation, such as an older List group and a current Link group representing the same value.
- Preserve genuinely distinct list-valued groups and separate ancestor scopes during migration.
- Remove the toolbar row-selection counter so selecting rows no longer adds text that can wrap the toolbar and push the table downward.
- Keep property-paste handling active after leaving or closing the source Base.

## Compatibility and usage

- Existing cell-copy, selected-cell paste, row-selection and internal row-move behavior are preserved.
- Clipboard links use vault-qualified wiki syntax, including file extensions. This clipboard fallback does not follow the vault's Markdown-link preference.
- Native Text/List property adaptation and external file dragging use capability-checked Obsidian internals. Compatibility can vary between Obsidian versions.
- For native List properties, paste into the add-item input after the existing entries. Editing an existing pill or using an unrecognized widget is outside this adapter's supported path.
- The property adapter recognizes a matching NosyGrid row-copy for two minutes; copy the rows again if that interval has elapsed.
- Multi-note Markdown-body paste and single-note property paste were confirmed by the user. Final interactive verification of automatic native multi-link List saving and external drop behavior is not recorded.
- Existing documentation screenshots remain genuine Obsidian captures from an earlier version, as documented in their provenance.

## Installation

Download `main.js`, `manifest.json` and `styles.css`, place them in your vault's `.obsidian/plugins/nosygrid/` folder, and reload NosyGrid.
