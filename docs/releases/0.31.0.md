# NosyGrid 0.31.0 — Primary group stacks

Arrange primary vertical groups side by side or stack them above and below one another. Each column grows independently, and groups in the same column share a resizable width. Arrangements are saved separately for each Base view and primary grouping scope.

## New

- Drag a primary group's header grip toward another group's top or bottom edge to insert it into that column.
- Drop near a left or right edge to move the group into an adjacent column. Nested contents move with their primary group.
- Resize a stack from any expanded member; double-click its resize handle to restore responsive sizing.
- Use Alt+Up/Down on a focused grip to reorder within a column, or Alt+Left/Right to move between columns and split at an outer boundary.
- Use insertion indicators and edge scrolling while arranging groups; press Escape to cancel a drag.
- Preserve saved positions for hidden and temporarily absent groups. Restore the arrangement after reopening or switching back from Horizontal layout.

## Compatibility and usage

- Stacking applies to the outermost grouping level in Vertical layout. Nested grouping keeps its existing layout and ordering behavior.
- Existing group order and widths seed the initial side-by-side arrangement. Joining a stack adopts that column's width.
- Whole-group arrangement changes are saved in the Base view and do not change note properties.
- The group-values menu follows column-first order. Flat menu reordering is available for singleton columns; use board grips when groups are stacked.
- Reset vertical group positions clears the saved stack arrangement and its stack-specific widths.
- Existing clipboard and native property-paste support from 0.30.0 is retained.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` from this release. Replace all three files in your vault's `.obsidian/plugins/nosygrid/` folder, then reload the plugin or restart Obsidian. Confirm that the installed version is `0.31.0`.
