# NosyGrid 0.26.2

Fixes the findings from Obsidian's automatic plugin checker while retaining the existing editing, grouping, dragging and persistence behavior.

- Move static board-row placement and list-item measurement height into CSS classes.
- Validate JSON, YAML, drag payloads and frontmatter at typed boundaries instead of propagating unsafe values.
- Use Obsidian DOM creation helpers for link suggestions and floating drag previews.
- Schedule and clear list-editor timers in their owning window for popout compatibility.
- Prefer the standard caret-position API, with a feature-detected fallback for older Electron versions; keep source offsets correct after aliased links.
- Retain filename control-character protection without a control-character regular expression.
- Remove unused code, unnecessary escapes/assertions and empty rollback handlers.
- Add a strict `npm run lint` gate to validation and release workflows. Development uses the TypeScript version supported by the lint parser; the plugin runtime and minimum Obsidian version are unchanged.

Install the three release files in `.obsidian/plugins/nosygrid/` and restart Obsidian. Requires Obsidian 1.10.2+ with Bases enabled.
