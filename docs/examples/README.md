# Reproduce the screenshots

1. Copy this folder’s contents into a vault folder named **Screenshot Demo**.
2. Enable Bases and NosyGrid, then open **NosyGrid Examples.base**.
3. Choose **Roadmap board** for Project sections and Status columns, or **Editable table** for inline editing.
4. In Editable table, click the Related cell for Inline editing to open its list editor.
5. In Roadmap board, open Group and expand **Status — group values** to inspect visibility, order and colors.

All twelve note records are fictional and have `demo: true`. The Base filter matches Markdown notes with that marker in a folder ending in `Screenshot Demo`; use a fresh test vault if you have another folder with the same suffix. Estimates total 34 (Atlas 18, Orion 16). The guide and this README are excluded because they lack the marker.

Colors, widths, groups and summary choices are supplied by the Base. Property type metadata belongs to your vault; set priority and estimate to Number and related to List if their inferred types differ. The actual captures use the existing Test Vault appearance, so your theme may look different. Opening the Base may normalize YAML formatting and save NosyGrid’s group availability cache.
