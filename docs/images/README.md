# Screenshot provenance

These PNGs are real window captures of NosyGrid in **Obsidian 1.15.0 on Windows**, captured on 2026-10-29 in Test Vault. The plugin source is the 0.26.3 summary fix (captured before the version metadata bump). The vault’s existing theme and settings control the appearance; other themes may differ.

The files in [../examples](../examples) are the actual fictional note data and Base configuration used. No image model, mock browser chrome, compositing, or replacement UI was used for these PNGs. Only rectangular cropping was applied to remove window chrome and unused space.

- `overview.png`: Roadmap board, Project horizontal sections and Status vertical columns. Estimates are Atlas 18, Orion 16, total 34. Crop `(0,75)-(2256,745)` from a 2256 × 1504 window capture.
- `editing.png`: Editable table, Related list cell for Inline editing in edit mode. Crop `(0,75)-(2256,930)` from a 2256 × 1504 window capture.
- `group-controls.png`: Actual Group popup with Status values expanded, showing visibility, drag order, colors and Add group. Crop `(1885,85)-(2207,816)` from a 2256 × 1504 window capture.

The earlier images came from a mock-browser development harness and were replaced. That harness now writes only to ignored `test-build/demo-images/`; it cannot overwrite these documentation images.
